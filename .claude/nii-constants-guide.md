# מדריך: קובץ nii-constants.json — מבנה ועדכון

> **קהל יעד:** מי שרוצה לעדכן ערכי ביטוח לאומי (ללא ידע בתכנות) ומפתח/ת שמבינ/ה את הארכיטקטורה.

---

## מהו הקובץ ומה תפקידו

`BTL/senior_rights/data/nii-constants.json` הוא **מקור האמת היחיד** לכל הערכים הכספיים שמגיעים מהמוסד לביטוח לאומי (ביט"ל). כל הדפים, המדריכים, והשאלונים באתר קוראים ממנו — לא כותבים ערכים בעצמם.

**כלל ברזל:** כשמתפרסם חוזר תשלומים חדש של ביט"ל — משנים **רק קובץ זה**. שאר הקבצים מתעדכנים אוטומטית.

---

## מבנה הקובץ

### שדה `_meta` — מידע על הקובץ

```json
"_meta": {
  "description": "קובץ נתונים מרכזי — המוסד לביטוח לאומי",
  "source": "חוזר תשלומים 33, ינואר 2026",
  "last_updated": "2026-01",
  "note": "לעדכון נתון — שנה את value בלבד. אל תשנה id או את שם המפתח."
}
```

יש לעדכן `source` ו-`last_updated` בכל פעם שמעדכנים את הקובץ.

---

### מבנה רשומה סטנדרטית

כל ערך בקובץ הוא אובייקט עם השדות הבאים:

```json
"pension_single_basic": {
  "id": "NII-001",
  "value": 1838,
  "type": "currency",
  "label": "קצבת זקנה בסיסית ליחיד/ה (גיל פרישה עד 80)",
  "updated": "2026-01"
}
```

| שדה | תיאור | מי משנה? |
|-----|-------|---------|
| **שם המפתח** (`pension_single_basic`) | המזהה הפנימי שכל הקוד משתמש בו | **לעולם לא לשנות** |
| `id` | מספר סידורי לתיעוד (`NII-XXX`) | לא לשנות |
| `value` | הערך המספרי — זה **מה שמוצג** לגולשים | **זה בלבד משתנה בעדכון** |
| `type` | סוג הערך: `currency` / `percent` / `rate` / `age` / `number` / `euro` | לא לשנות |
| `label` | תיאור קריא לבן-אדם (לתיעוד בלבד, לא מוצג ישירות) | אפשר לשנות בזהירות |
| `updated` | תאריך עדכון אחרון (`YYYY-MM`) — `fixed` אם הערך קבוע בחוק | לעדכן בכל שינוי |
| `source` *(אופציונלי)* | קישור למקור רשמי | ממלאים כשיש |

## איך לעדכן ערך — צעד אחר צעד

### עבור מי שאינו מפתח

1. **מצא את הערך** — חפש לפי `label` (Ctrl+F בעורך טקסט) לדוגמה: `"קצבת זקנה בסיסית"`
2. **שנה את `value` בלבד** — מספר שלם לשקלים, עשרוני לאחוזים/שיעורים
3. **עדכן את `updated`** לתאריך החוזר הנוכחי (פורמט: `"2026-01"`)
4. **עדכן את `_meta.source`** לשם החוזר החדש
5. **שמור** — השינוי יופיע בכל הדפים שמשתמשים בערך זה

**לא לגעת ב:** שם המפתח, `id`, `type`.

### דוגמה — עדכון קצבת זקנה בסיסית

**לפני:**
```json
"pension_single_basic": {
  "id": "NII-001",
  "value": 1838,
  "type": "currency",
  "label": "קצבת זקנה בסיסית ליחיד/ה (גיל פרישה עד 80)",
  "updated": "2026-01"
}
```

**אחרי (עדכון ינואר 2027):**
```json
"pension_single_basic": {
  "id": "NII-001",
  "value": 1925,
  "type": "currency",
  "label": "קצבת זקנה בסיסית ליחיד/ה (גיל פרישה עד 80)",
  "updated": "2027-01"
}
```

## איך הערכים מגיעים לדפים — לקורא/ת טכני/ת

### שני מסלולים

#### מסלול 1: מדריכי HTML (guides)

כל דף HTML (`nursing_home_guide.html`, `survivors_benefits_guide_2026.html` וכו') טוען את הקובץ בעצמו עם `fetch`:

```javascript
const response = await fetch('../data/nii-constants.json');
const nii = await response.json();
```

ואז קורא לפונקציה `c(key)` שמחזירה את `nii[key].value`:

```javascript
function c(key) { return nii[key]?.value ?? fallback; }

// שימוש בתוך הדף:
document.getElementById('pension-basic').textContent = c('pension_single_basic').toLocaleString('he-IL') + '₪';
```

אם הטעינה נכשלת — מוצג באנר שגיאה צהוב בראש הדף.

---

#### מסלול 2: שאלונים (questionnaire-engine.js + niiMapping)

שאלוני JSON (`income-supplement-eligibility.json` וכו') מכילים שדה `niiMapping` — מפה שמקשרת בין שדות חישוב לבין מפתחות NII:

```json
"niiMapping": {
  "thresholds.single_under70": "income_supplement_single_under70",
  "thresholds.couple_under70": "income_supplement_couple_under70",
  "vehicle.threshold_extended": "vehicle_threshold_extended"
}
```

**`questionnaire-engine.js`** — בטעינה:
1. טוען את קובץ ה-JSON של השאלון
2. רואה שיש `niiMapping` — טוען גם את `nii-constants.json`
3. מפעיל `applyNiiMapping()` שמעתיק כל ערך מ-NII לתוך `calculationRules`
4. השאלון מחשב זכאות בזמן אמת עם הערכים הנכונים

```javascript
applyNiiMapping(nii) {
    Object.entries(this.data.niiMapping).forEach(([rulePath, niiKey]) => {
        // rulePath = "thresholds.single_under70"
        // niiKey   = "income_supplement_single_under70"
        // → calculationRules.thresholds.single_under70 = nii["income_supplement_single_under70"].value
    });
}
```

## הוספת שדה חדש — למפתח/ת

1. בחר מפתח תיאורי ב-snake_case באנגלית (לדוגמה: `new_benefit_amount`)
2. הוסף `id` ייחודי בסדר עולה (`NII-XXX`)
3. מלא `value`, `type`, `label`, `updated`
4. אם הערך משמש בשאלון — הוסף שורה ל-`niiMapping` בקובץ ה-JSON של השאלון:
   ```json
   "niiMapping": {
     "thresholds.new_field": "new_benefit_amount"
   }
   ```
5. ודא שהשדה `calculationRules.thresholds.new_field` קיים בשאלון ומשמש בחישוב
