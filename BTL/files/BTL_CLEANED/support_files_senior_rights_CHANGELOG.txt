# סיכום שינויים - שאלון בדיקת זכאות להשלמת הכנסה (ינואר 2026)
## 📝 סכום כללי
שאלון בדיקת זכאות להשלמת הכנסה עבר עדכון קיצוני המטמיע חישוב הזכאות המדויק לפי חוקי הביטוח הלאומי בישראל.
**תאריך**: ינואר 2026
**גרסה**: 2.0
**סטטוס**: ✅ מוכן לשימוש

## 🔧 קבצים שהשתנו
### 1. [`income-supplement-eligibility.json`](questionnaires/income-supplement-eligibility.json)
**שינויים**: רואיסטרוקטורה מלאה
#### קודם: 16 שאלות
- בדיקות בנפרד אם כנסה "עולה על" תקרה
- לא חישוב אמיתי
- תוצאות סטטיות בלבד
#### עכשיו: 9 שאלות
- איסוף כל ההכנסות
- חישוב דינמי
- תוצאה עם פרטי חישוב
#### שאלות חדשות/שונות:
- `q0a_has_children` - האם יש ילדים (בדיקה לשאלון הגדרת ילד)
- `q0b_family_composition` - בחר קטגוריה (מעכסן את התקרה)
- `q1_old_age_pension` - קצבה (מספר)
- `q2_pension_income` - פנסיה (מספר)
- `q3_work_income` - עבודה (מספר)
- `q4_imputed_income` - הכנסה רעיונית (רדיו → sub-questionnaire)
- `q5_israel_resident` - תושב ישראל (כן/לא)
- `q6_work_status` - מצב עבודה (רדיו)
- `q7_vehicle` - רכב יקר (רדיו)
#### קבוצות כללים חדשות:
```json
"calculationRules": {
"familyCompositions": { ... },
"incomeDeductions": {
"pensionIncome": { exemption: 2600, deductionRate: 0.33 },
"workIncome": { exemption: 3800, deductionRate: 0.60 }
}
}
```
#### תוצאה דינמית חדשה:
```json
"calculate_eligibility": {
"dynamic": true,
"fields": ["family_composition", "total_income", "deductions", ...]
}
```

### 2. [`questionnaire-engine.js`](questionnaire-engine.js)
**שינויים**: הוספת לוגיקת חישוב
#### שיטות חדשות:
**`showDynamicResult(resultKey)`** [שורה 792]
- בודקת אם `result.dynamic === true`
- מציגה תוצאה דינמית עם חישוב
- בונה טבלה של הכנסות וקיזוזים
- מוצגת זכאות או סיבת אי-זכאות
**`calculateIncomeSupplementEligibility()`** [שורה 840]
- מחשבת סה"כ הכנסה נטו
- משווה לתקרה לפי קטגוריה
- חוזרת:
- `eligible`: true/false
- `netIncome`: סה"כ מחושב
- `estimatedSupplement`: סכום ההשלמה
- `reason`: הסבר אם לא זכאי
**`calculatePensionDeduction(pensionIncome, rules)`** [שורה 957]
- חישוב קיזוז פנסיה:
- פטור: 2,600₪
- קיזוז: 33% מהעודף
**`calculateWorkDeduction(workIncome, rules)`** [שורה 965]
- חישוב קיזוז עבודה:
- פטור: 3,800₪
- קיזוז: 60% מהעודף
#### שינוי קיים:
**`setupNumberInputListeners(question)`** [שורה 384]
- תמיכה ב-`storeAs` מתכונת JSON
- מאפשר אחסון בשם מותאם
- דוגמה: `storeAs: "q1_old_age_pension_amount"`

## 📊 דוגמה: מה השתנה
### קודם (v1.0)
```
שאלה 1: קצבה עולה על תקרה? כן/לא
שאלה 2: פנסיה עולה על תקרה? כן/לא
שאלה 3: עבודה עולה על תקרה? כן/לא
...
תוצאה: "לא זכאי - הכנסה עולה על התקרה"
```
❌ **בעיה**: לא בדק את ההכנסה הכוללת, רק בנפרד
### עכשיו (v2.0)
```
שאלה 1: כמה קצבה? [3500]
שאלה 2: כמה פנסיה? [1000]
שאלה 3: כמה עבודה? [2000]
שאלה 4: כמה הכנסה רעיונית? [0]
...
✓ תוצאה:
קצבה:    3,500₪
פנסיה:   (1,000-2,600) × 33% = 0₪
עבודה:   (2,000-3,800) × 60% = 0₪
הכנסה רעיונית: 0₪
─────────────────────
סה"כ:    3,500₪
תקרה:    4,375₪
──────────────────────
✓ זכאי להשלמה של: 875₪
```
✅ **פתרון**: חישוב מלא וגלוי של הזכאות
