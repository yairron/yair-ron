# תיעוד מערכת כפל קצבאות
מערכת זו בודקת אילו קצבאות ביטוח לאומי ניתן לקבל במקביל, ומציגה את התוצאות למשתמש.
---
## קבצי המערכת
### נתונים
| קובץ | תפקיד |
|------|--------|
| `support_files/files/Matriza_kitsbaot_script.md` | מקור הנתונים – רשימת 57 קצבאות וטבלת צירופים אפשריים. מתעדכן אוטומטית על ידי btl_collect.js |
| `support_files/json/btl_benefit_combinations_results.json` | תוצאות בפועל מהאתר – עד 621 צירופים עם הטקסט המלא מהביטוח הלאומי |
### סקריפטים (Node.js + Playwright)
| קובץ | תפקיד |
|------|--------|
| `senior_rights/data/btl_collect.js` | שלב א – לכל קצבה A קורא מהאתר אילו B אפשריים, ומעדכן את ה-MD |
| `senior_rights/data/btl_step2.js` | שלב ב – עובר על צירופי A+B, שולח לאתר, חולץ תוצאה ושומר ב-btl_benefit_combinations_results.json |
### ממשק משתמש
| קובץ | תפקיד |
|------|--------|
| `support_files/benefit-combinations.html` | דף HTML – מחשבון האפשרות לקבל יותר מקצבה אחת |
| `index.html` | דף הבית – מכיל קישור למחשבון תחת "כלי עזר" |
---
## סדר עבודה
### שלב א – עדכון רשימת הצירופים האפשריים
```bash
cd BTL/senior_rights/data
node btl_collect.js --test    # בדיקה על קצבה אחת
node btl_collect.js           # הרצה מלאה על כל 57 קצבאות
```
מעדכן את `Matriza_kitsbaot_script.md`.
### שלב ב – איסוף תוצאות מהאתר
```bash
cd BTL/senior_rights/data
node btl_step2.js --test    # בדיקה על צירוף אחד
node btl_step2.js           # 50 צירופים, חוזר על כך עד השלמת כל 621
```
מעדכן את `btl_benefit_combinations_results.json`. כל הרצה ממשיכה מאיפה שעצרה.
