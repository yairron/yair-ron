# מערכת ניהול נתונים דינמיים - זכויות אזרחים ותיקים
## 📌 מטרת המערכת
מערכת זו מאפשרת לנהל במקום מרכזי אחד את כל הנתונים שמשתנים תקופתית (סכומי קצבאות, אחוזים, תקרות הכנסה וכו').
במקום לחפש ולעדכן ידנית 93 מופעים של נתונים ב-`rights-data.js`, כעת ניתן:
- לעדכן את הנתונים במקום אחד
- לעקוב אחרי תאריכי העדכון של כל נתון
- לקבל דוח מפורט על כל המופעים
- להימנע מטעויות עקב עדכון חלקי
---
## 📁 הקבצים במערכת
### 1. `dynamic-values.json` - קובץ הנתונים המרכזי
**מה זה:** כל הנתונים המשתנים במקום אחד
**מתי לערוך:** כאשר יש עדכון מביטוח לאומי (בדרך כלל ינואר כל שנה)
**מבנה:**
```json
{
"values": {
"BASIC_PENSION_SINGLE": {
"fieldName": "קצבה בסיסית ליחיד",
"value": 1795,
"displayValue": "₪1,795",
"updateDate": "2025-01-01",
"explanation": "קצבת זקנה בסיסית...",
"usageLocations": ["סכומי קצבה", "דוגמאות חישוב"]
}
}
}
```
### 2. `find-dynamic-values.js` - סקריפט איתור
**מה זה:** מוצא את כל המופעים של כל נתון ב-`rights-data.js`
**מתי להריץ:** לפני ואחרי עדכון, כדי לוודא שהכל מעודכן
**שימוש:**
```bash
cd BTL/senior_rights/data
node find-dynamic-values.js
```
### 3. `dynamic-values-report.txt` - דוח מפורט
**מה זה:** דוח אוטומטי של כל המופעים
**מתי להסתכל:** לבדיקה ולתיעוד
### 4. `pension-amounts-2025.json` - נתוני קצבאות (קיים)
**מה זה:** JSON מפורט יותר עם מבנה היררכי של נתוני קצבאות
---
## 🔄 תהליך עדכון נתונים
### תרחיש: ביטוח לאומי פרסם עדכון לינואר 2026
#### שלב 1: הכנה
```bash
# גיבוי
cp rights-data.js rights-data.js.backup
cp dynamic-values.json dynamic-values.json.backup
```
#### שלב 2: עדכון הנתונים המרכזיים
1. פתח את `dynamic-values.json`
2. חפש את הנתון שהשתנה (למשל: קצבה בסיסית)
3. עדכן:
- `value` - הערך המספרי
- `displayValue` - הערך המעוצב (עם ₪)
- `updateDate` - תאריך העדכון
**דוגמה:**
```json
"BASIC_PENSION_SINGLE": {
"fieldName": "קצבה בסיסית ליחיד",
"value": 1850,              // ⬅️ עדכנו מ-1795
"displayValue": "₪1,850",   // ⬅️ עדכנו מ-₪1,795
"updateDate": "2026-01-01", // ⬅️ עדכנו התאריך
"explanation": "קצבת זקנה בסיסית ליחיד מגיל פרישה עד גיל 80"
}
```
#### שלב 3: בדיקה לפני החלפה
```bash
# הרץ את סקריפט האיתור כדי לראות כמה מופעים יש
node find-dynamic-values.js
```
הפלט יראה:
```
📌 קצבה בסיסית ליחיד (BASIC_PENSION_SINGLE)
ערך: ₪1,795
מספר מופעים: 20
מיקומים:
1. שורה 47: <li><strong>יחיד/ה:</strong> ₪1,795 לחודש</li>
2. שורה 50: <li><strong>זוג שניהם מקבלים:</strong> ₪1,795...
...
```
#### שלב 4: עדכון ידני ב-rights-data.js
**כרגע זה ידני**, אבל אפשר:
**אופציה 1: חיפוש והחלפה (Find & Replace)**
1. פתח את `rights-data.js` בעורך
2. חפש: `₪1,795`
3. החלף ב: `₪1,850`
4. סקור כל מופע לפני החלפה!
**אופציה 2: סקריפט אוטומטי (עתידי)**
אפשר ליצור סקריפט שיחליף אוטומטית:
```bash
node replace-dynamic-values.js
```
#### שלב 5: אימות
```bash
# הרץ שוב לבדיקה
node find-dynamic-values.js
# בדוק שהערך החדש מופיע בכל המקומות הנכונים
```
#### שלב 6: בדיקה בדפדפן
1. פתח את `senior_rights.html`
2. בדוק שהערכים מעודכנים נכון
3. בדוק דוגמאות חישוב

## 💡 טיפים ושגרות מומלצות
### ✅ DO - כן לעשות
1. **תמיד עשה גיבוי** לפני עדכון
2. **עדכן את metadata.lastUpdate** בראש `dynamic-values.json`
3. **הרץ find-dynamic-values.js** לפני ואחרי
4. **סקור ידנית** את השינויים החשובים
5. **בדוק בדפדפן** לפני פרסום
### ❌ DON'T - לא לעשות
1. אל תערוך ישירות את `rights-data.js` בלי לעדכן את `dynamic-values.json`
2. אל תשכח לעדכן את `updateDate` בכל שדה שהשתנה
3. אל תסמוך על "החלף הכל" בלי בדיקה - יש ערכים שחוזרים על עצמם
