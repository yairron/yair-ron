🎯 מה יש כאן?

במקום לחפש ולעדכן 93 מופעים של סכומים באתר,
כעת יש מערכת שעוזרת לעקוב אחרי הכל במקום אחד!


📁 הקבצים החשובים:

1. dynamic-values.json
   ✓ כל הנתונים שמשתנים (קצבאות, אחוזים וכו')
   ✓ כאן תעדכן כשביטוח לאומי מפרסם שינויים

2. find-dynamic-values.js
   ✓ סקריפט שמוצא היכן כל נתון מופיע
   ✓ הרץ: node find-dynamic-values.js

3. dynamic-values-report.txt
   ✓ דוח אוטומטי - רשימה מלאה של כל המופעים


🔄 איך לעדכן נתונים?

שלב 1 - גיבוי
───────────────
העתק את הקבצים המקוריים:
  ✓ rights-data.js → rights-data.js.backup
  ✓ dynamic-values.json → dynamic-values.json.backup


שלב 2 - בדיקה מה משתנה
───────────────────────────
הרץ את הסקריפט:
  cd BTL/senior_rights/data
  node find-dynamic-values.js

תראה דוח מפורט, למשל:

  📌 קצבה בסיסית ליחיד (BASIC_PENSION_SINGLE)
     ערך: ₪1,795
     מספר מופעים: 20

     מיקומים:
     1. שורה 47: <li>יחיד/ה: ₪1,795 לחודש</li>
     2. שורה 50: <li>זוג: ₪1,795 לכל אחד...</li>
     ...


שלב 3 - עדכון ב-dynamic-values.json
────────────────────────────────────────
פתח את dynamic-values.json וערוך:

  "BASIC_PENSION_SINGLE": {
    "value": 1850,              ← שנה את המספר
    "displayValue": "₪1,850",   ← שנה את התצוגה
    "updateDate": "2026-01-01"  ← תאריך עדכון
  }


שלב 4 - עדכון ב-rights-data.js
────────────────────────────────
אופציה A: חיפוש והחלפה ידני
  1. פתח rights-data.js
  2. חפש: ₪1,795
  3. החלף ב: ₪1,850
  4. סקור כל מופע!

אופציה B: אוטומטי (עתידי)
  node replace-dynamic-values.js


שלב 5 - אימות
──────────────
1. הרץ שוב: node find-dynamic-values.js
2. וודא שהערך החדש מופיע בכל המקומות
3. פתח את האתר בדפדפן ובדוק
