# מפרט פונקציה: קביעת מעמד משפחתי וחישוב קצבת בסיס — קצבת אזרח ותיק

**קובץ:** `classifyAndComputePension.js`  
**מקור נתונים:** `nii-constants.json` (חוזר תשלומים 33, ינואר 2026)

## מטרת הפונקציה

הפונקציה עושה שני דברים ברצף:

1. **קובעת** האם לתובע/ת מגיעה תוספת בן/בת זוג בקצבתו/ה
2. **מחשבת** את **קצבת הבסיס הסופית** — הסכום שממנו האלגוריתם מחשב את הזכאות לאחר הפחתות הכנסה

### מהי "קצבת הבסיס הסופית"

זהו **הסכום המרבי** שהתובע/ת יכול/ה לקבל לפני בדיקת ההכנסות. האלגוריתם הבא (שאינו חלק מפונקציה זו) יוריד ממנה סכומים בגין הכנסות מעבודה, הכנסות פסיביות וכו'.

אם לאחר הורדת ההפחתות הסכום שנותר נמוך מ-**184 ₪** — אין זכאות לקצבה כלל. סכום זה (10% מהקצבה הבסיסית ליחיד/ה) מוחזר כ`סףמינימלי` ונשאר קבוע ללא קשר למצב המשפחתי.

## נוסחת החישוב

```
קצבה בסיסית לפי גיל התובע/ת:
    גיל עד 79  →  1,838 ₪  (pension_single_basic)
    גיל 80+    →  1,941 ₪  (pension_single_over80)

קצבה לפני ותק =
    קצבה בסיסית לפי גיל
  + תוספת בן/בת זוג × [1 אם יש_תוספת_זוג, 0 אחרת]   → 924 ₪
  + תוספת ילד × ילדים לחישוב                           → 581 ₪ לילד

קצבת בסיס סופית =
    קצבה לפני ותק × (1 + ותק מחושב / 100)
```

### הגבלות הותק

- **ותק מחושב** = min(ותק שהוזן, 50) — מוגבל למקסימום 50% (25 שנות ביטוח)
- **ותק מוזן כמספר זוגי** — 2% לכל שנת ביטוח מלאה (הפונקציה מעגלת מטה לזוגי הקרוב)

### דוגמאות

| תובע/ת | ילדים | בן/בת זוג | ותק | חישוב | תוצאה |
|--------|-------|-----------|-----|-------|-------|
| גיל 70 | 0 | כן (תלוי) | 20% | (1,838 + 924) × 1.20 | 3,314 ₪ |
| גיל 70 | 1 | כן (תלוי) | 20% | (1,838 + 924 + 581) × 1.20 | 4,012 ₪ |
| גיל 82 | 0 | לא | 0% | 1,941 × 1.00 | 1,941 ₪ |
| גיל 68 | 2 | לא | 50% | (1,838 + 581×2) × 1.50 | 4,500 ₪ |
| גיל 75 | 0 | כן (תלוי) | 0% | (1,838 + 924) × 1.00 | 2,762 ₪ |

## חיבור לאלגוריתם הקיים — במקום מה `קצבתבסיססופית` נכנסת

באלגוריתם הנוכחי (`buildSummaryAndResult` בקובץ `age_pension_eligibility_calculator.html`) מחושב הסכום הבסיסי כך:

```javascript
// קוד קיים — שורות 1483–1494
const pensionKey = getFamilyPensionKey(household.category, age, childrenCount);
const familyPensionBase = getNumericNiiValue(pensionKey);   // סכום גולמי לפי מפתח
const cappedVetek = Math.min(seniorityMax, Math.max(0, vetek));
const basePension = familyPensionBase * (1 + (cappedVetek / 100));  // ← basePension
```

**`קצבתבסיססופית` מחליפה את `basePension`.**

כל מקום בקוד שמשתמש ב-`basePension` — למבחן הכנסות, לחישוב ניכויים, להשוואה לסף המינימלי — יקבל במקומו את `קצבתבסיססופית` שמוחזרת מהפונקציה החדשה.

הסף המינימלי לזכאות (שורה 1498 בקוד):
```javascript
const minPartialPension = pensionSingleBasic * 0.1;  // = 184 ₪
```
מוחזר כ-`סףמינימלי` — ערכו **184 ₪** — ואינו משתנה לפי הרכב משפחתי.

- תוספת דחיית קצבה
- זכאות לגמלה מיוחדת / השלמת הכנסה
- תקופת אכשרה

### מה צריך שיפור / החלטות פתוחות

1. **ערכי שדה `משךנישואין` לאישה עם בן זוג גבר:** הטופס מכיל שתי אפשרויות בלבד — `מעלשנה` ו-`פחותמשנה`. "פחות משנה עם ילד" קיים **רק בטופס לגבר** ואינו רלוונטי לאישה.

2. **שדה `הכנסה` של בן/בת זוג:** הפונקציה מקבלת סכום מספרי (₪ לחודש). המחשבון הנוכחי לא אוסף ישירות את הכנסת בן/בת הזוג לצורך בדיקת ה-7,848 ₪ — רק כשהוא בגיל 45–67 (גבר) / 50–70 (אישה). יש לוודא שהממשק מעביר ערך זה.

3. **קצבת זיקנה לבן/בת זוג:** בטופס הנוכחי, בן/בת זוג המקבל/ת קצבת זיקנה אינו/ה פוסל/ת — אך גם לא מוסיף/ה תוספת (כי זכאי/ת בנפרד). לוגיקה זו תשפיע על בחירת **מפתחות מבחן ההכנסה** בשלב הבא (הפחתות). יש לתעד זאת שם.

4. **עגול לש"ח שלם:** `קצבתבסיססופית` מעוגלת ל-`Math.round`. אם הדרישה היא חיתוך מטה — יש להחליף ל-`Math.floor`.
