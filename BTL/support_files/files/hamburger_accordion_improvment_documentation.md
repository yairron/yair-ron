### שלב א׳ — ניתוח המבנה הטכני

**מה נבדק:**
- `senior_rights_full.html` טוען נתונים מ-`senior_rights_full_data.js` דרך `PAGE_DATA.contentFn()`
- הפונקציה `processNestedHeadings()` רצה לאחר הרנדור וממירה תגיות `h3`–`h5` לאלמנטי `.sub-accordion` ב-DOM
- כאשר `.sub-accordion` נוצר, הכותרת המקורית **מוחלפת לגמרי** ב-DOM — כלומר אם ה-`id` נשאר על הכותרת, הוא נעלם עם הסרתה

**מסקנה:** צריך להעביר את ה-`id` מהכותרת לאלמנט ה-`.sub-accordion` החדש **בזמן היצירה**, ולהוסיף פונקציה שתפתח את האקורדיון הנכון לפי ה-hash ב-URL.

### שלב ג׳ — באגים שנמצאו לאחר הפעלה ותיקונם

#### באג 1: "undefined" מופיע לפני כל שורה בתפריט

**מה נראה:** כל שורת תפריט בסקשיין 🌟 הציגה את המילה "undefined" לפני הטקסט.

**מה בדקנו:** הפונקציה `buildMenuHTML` ב-`hamburger-nav.js` בונה HTML עבור כל פריט כך:
```javascript
`<span>${item.icon} ${item.text}</span>`
```
פריטי ה-children החדשים (כמו `{ text: '👴 קצבת אזרח ותיק', children: [...] }`) לא כוללים שדה `icon` — האמוג'י שולב ישירות בשדה `text`. JavaScript ממיר `undefined` למחרוזת `"undefined"`.

**מה תוקן:** שני המקומות ב-`buildMenuHTML` שמשתמשים ב-`item.icon` שונו:
```javascript
// לפני
`${item.icon} ${item.text}`

// אחרי
const iconHtml = item.icon ? item.icon + ' ' : '';
`${iconHtml}${item.text}`
```

#### באג 2: לחיצה על קישור בתפריט לא פתחה את האקורדיון

**מה נראה:** לחיצה על קישור כמו `1.1 גילאי פרישה וזכאות` לא פתחה כלום בדף.

**מה בדקנו ומה מצאנו — שני כשלים נפרדים:**

**כשל א׳ — אין `hashchange` listener:**
כאשר המשתמש נמצא כבר בדף `senior_rights_full.html` ולוחץ על קישור `#op-11`, הדפדפן מבצע ניווט hash באותו עמוד (ללא טעינה מחדש). הפונקציה `openFromHash()` נקראת רק פעם אחת — לאחר טעינת התוכן — ולא שוב בניווטים עתידיים.

**תיקון:** הוסף listener לאירוע `hashchange` מיד לאחר הקריאה הראשונה ל-`openFromHash()`:
```javascript
openFromHash();
window.addEventListener('hashchange', openFromHash);  // ← שורה חדשה
```

**כשל ב׳ (הכשל העיקרי) — לולאת הפתיחה דילגה על אלמנט היעד עצמו:**
ב-`openFromHash()`, הלולאה שמוסיפה `active` לשרשרת האבות התחילה מ-`subTarget.parentElement` במקום מ-`subTarget`:
```javascript
// שגוי — מדלג על היעד עצמו
let el = subTarget.parentElement;
while (el) {
    if (el.classList.contains('accordion') || el.classList.contains('sub-accordion')) {
        el.classList.add('active');
    }
    el = el.parentElement;
}
```
כתוצאה, האלמנט `#op-11` עצמו לא קיבל `active` אף פעם, ולכן התוכן שלו לא הוצג — למרות שה-accordion הראשי (`old_age_pension`) נפתח.

**תיקון:** הלולאה מתחילה מ-`subTarget` עצמו:
```javascript
// נכון — מוסיף active לעלה ולכל האבות
let el = subTarget;
```
כך, קישור לאקורדיון מקונן עמוק (כמו `#op-12a`, שהוא בן של "1.2 תקופת אכשרה") יפתח נכון את כל שלוש הרמות: `#op-12a` עצמו, את "1.2" שמעליו, ואת הקטגוריה הראשית (`old_age_pension`).

#### `openFromHash()` — מצב כפול

מכיוון שאקורדיונים ראשיים ממוינים לפי `data-category` ולא `id`, הפונקציה מנסה שני מסלולים:

```javascript
function openFromHash() {
    const hash = decodeURIComponent(window.location.hash.slice(1));
    if (!hash) return;
    // מסלול 1: אקורדיון ראשי לפי data-category
    const byCat = document.querySelector(`.accordion[data-category="${hash}"]`);
    if (byCat) {
        document.querySelectorAll('.accordion.active').forEach(a => a.classList.remove('active'));
        byCat.classList.add('active');
        setTimeout(() => byCat.scrollIntoView({ behavior: 'smooth', block: 'start' }), 450);
        return;
    }
    // מסלול 2: sub-accordion לפי id (נוצר מ-h4)
    const target = document.getElementById(hash);
    if (!target) return;
    document.querySelectorAll('.accordion.active').forEach(a => a.classList.remove('active'));
    let el = target;
    while (el) {
        if (el.classList.contains('accordion') || el.classList.contains('sub-accordion')) {
            el.classList.add('active');
        }
        el = el.parentElement;
    }
    setTimeout(() => target.scrollIntoView({ behavior: 'smooth', block: 'start' }), 450);
}
openFromHash();
window.addEventListener('hashchange', openFromHash);
```

## שלב 4 — המרת ענפי תפריט ל"עלים ישירים" (leaf node conversion)

### רקע

לאחר בניית ה-`senior_citizens_rights_2026.html` ותפריטו, התברר שחלק מהפריטים בתפריט ה-hamburger היו **parent nodes** עם תתי-תפריט (children). הבעיה: כשיש תת-אקורדיון עם 5–8 ילדים, הצגתם בתפריט יוצרת עומס. עדיף להפוך אותם לקישורים ישירים ("עלים") שפותחים את ה-accordion הראשי — והמשתמש רואה בתוכו את כל הסעיפים באופן טבעי.

```javascript
function openFromHash() {
    const hash = decodeURIComponent(window.location.hash.slice(1));
    if (!hash) return;
    const target = document.getElementById(hash);
    if (!target) return;
    document.querySelectorAll('.accordion.active').forEach(a => a.classList.remove('active'));
    let el = target;
    while (el) {
        if (el.classList.contains('accordion') || el.classList.contains('sub-accordion')) {
            el.classList.add('active');
        }
        el = el.parentElement;
    }
    setTimeout(() => target.scrollIntoView({ behavior: 'smooth', block: 'start' }), 450);
}
```

openFromHash();

**2. `buildAccordions()`** — הוסף `accordion.id = data.id;` אחרי `accordion.className = 'accordion';`

**3. `openFromHash()`** — חדשה; מטפלת במעבר טאב ידני (עוקפת את `event.target` של `switchTab()`):
```javascript
function openFromHash() {
    const hash = decodeURIComponent(window.location.hash.slice(1));
    if (!hash) return;
    const target = document.getElementById(hash);
    if (!target) return;
    document.querySelectorAll('.tab-content').forEach(t => t.classList.remove('active'));
    document.getElementById('info').classList.add('active');
    document.querySelectorAll('.tab-button').forEach(btn =>
        btn.classList.toggle('active', btn.getAttribute('onclick') === "switchTab('info')")
    );
    document.querySelectorAll('.accordion.active').forEach(a => a.classList.remove('active'));
    target.classList.add('active');
    setTimeout(() => target.scrollIntoView({ behavior: 'smooth', block: 'start' }), 450);
}
```

**4. חיווט ב-`initializePage()`** — מיד אחרי `buildAccordions()`, לפני ה-`await`:
```javascript
buildAccordions();
openFromHash();
window.addEventListener('hashchange', openFromHash);
```

**5. שינויים ב-`hamburger-nav.js`:**

| `highlight(text, query)` | מוסיף `<mark>` על מילים תואמות |
