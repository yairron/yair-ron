## 🚀 התקנה ופריסה - שלב אחר שלב

### שלב 1: העלאה ל-GitHub

1. **צור repository חדש** ב-GitHub בשם `btl` (או כל שם אחר)

2. **העלה את כל הקבצים:**
   - `index-auto-update.html` (שנה שם ל-`index.html`)
   - `package.json` (שנה שם מ-`package-auto-update.json`)
   - `netlify.toml`
   - `README.md`
   - תיקייה `.github/workflows/` עם `update-data.yml`
   - תיקייה `scripts/` עם `update-data.js`

3. **Commit וPush:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Auto-update system"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/btl.git
   git push -u origin main
   ```

---

### שלב 2: הגדרת Anthropic API Key ב-GitHub

**חשוב מאוד!** בלי זה העדכון האוטומטי לא יעבוד.

1. היכנס לחשבון GitHub שלך
2. לך ל-repository שיצרת (`btl`)
3. לחץ על **Settings** (הגדרות)
4. בתפריט השמאלי: **Secrets and variables** → **Actions**
5. לחץ **New repository secret**
6. הוסף:
   - **Name:** `ANTHROPIC_API_KEY`
   - **Value:** המפתח שלך מ-[Anthropic Console](https://console.anthropic.com/)
7. לחץ **Add secret**

---

### שלב 3: חיבור ל-Netlify

1. היכנס ל-[Netlify](https://www.netlify.com)
2. לחץ **Add new site** → **Import an existing project**
3. בחר **GitHub** והתחבר
4. בחר את ה-repository `btl`
5. הגדרות בניה:
   - **Build command:** השאר ריק
   - **Publish directory:** `./`
6. לחץ **Deploy site**

---

### שלב 4: בדיקה ראשונית

1. **הרץ את העדכון הראשון ידנית:**
   - ב-GitHub, לך ל-**Actions**
   - בחר **"עדכון אוטומטי של בסיס נתונים"**
   - לחץ **Run workflow** → **Run workflow**
   - המתן 2-3 דקות

2. **בדוק את התוצאות:**
   - תיקייה חדשה `data/` תיווצר
   - בתוכה יהיו `rights-data.json` ו-`rights-data.js`
   - Netlify יפרוס מחדש אוטומטית

3. **בדוק את האתר:**
   - פתח את האתר ב-`https://your-site.netlify.app`
   - תראה את המידע המעודכן עם תאריך העדכון

## 🕐 לוח זמנים

### עדכון אוטומטי:
- **כל יום בשעה 02:00 UTC** (04:00 בישראל בחורף, 05:00 בקיץ)
- ניתן לשנות ב-`.github/workflows/update-data.yml`

### דוגמאות לשינוי תזמון:

**כל 12 שעות:**
```yaml
schedule:
  - cron: '0 */12 * * *'
```

**כל יום ראשון בבוקר:**
```yaml
schedule:
  - cron: '0 6 * * 0'
```

**כל שעתיים:**
```yaml
schedule:
  - cron: '0 */2 * * *'
```

### ❌ העדכון נכשל?

1. ה-API Key נכון ב-GitHub Secrets?

## 💰 עלויות

### GitHub Actions:
- ✅ **חינם לחלוטין** עד 2,000 דקות/חודש
- עדכון יומי = ~3 דקות/יום = ~90 דקות/חודש
- **הרבה מתחת למכסה!**

- תלוי במכסה שלך

- עדכון יומי = ~180 קריאות/חודש
- **עלות משוערת: $5-10/חודש** (תלוי בתוכנית)

### Netlify:
- ✅ **חינם לחלוטין** (תוכנית Starter)
