## 4. בעיות ומגבלות נוכחיות

### 🔴 בעיה קריטית #1: אין קינון היררכי אמיתי

**הבעיה**:
הפונקציה רצה **פעם אחת בלבד** על `.accordion-body` הראשי. כותרות H3 שנמצאות **בתוך** תת-אקורדיון שנוצר מ-H2 **לא מעובדות**.

**הסיבה**:
- בשורה 622 מוצאים את כל H2, H3 ברמה הראשונה
- אבל כשממירים H2 לתת-אקורדיון, ה-H3 שבתוכו עוברים ל-`.sub-accordion-body` (שורה 661)
- הפונקציה לא רצה רקורסיבית על `.sub-accordion-body`

**תוצאה**:
H3 יישארו ככותרות רגילות, לא יהפכו לתתי-אקורדיונים מקוננים בתוך H2.

---

### 🔴 בעיה קריטית #2: לוגיקת הקינון שגויה

**הבעיה**:
הקוד מחפש "עד הכותרת הבאה מאותה הרמה **או נמוכה יותר**":
```javascript
while (nextElement && !['H2', 'H3'].includes(nextElement.tagName))
```

**מה שצריך לקרות בקינון היררכי**:
- H2 צריך לאסוף תוכן עד H2 הבא (לא עד H3)
- H3 צריך לאסוף תוכן עד H3 או H2 הבא
- H4 צריך לאסוף תוכן עד H4/H3/H2 הבא

**הקוד הנוכחי**:
- H2 יעצור גם אם ימצא H3 (זה לא נכון - H3 צריך להיות **בתוך** H2)

#### ב. לוגיקת היררכיה
- H2 אוסף תוכן עד H2 הבא (עוצר רק ב-H2, לא ב-H3-H6)
- H3 אוסף תוכן עד H3 או H2 הבא
- H4 אוסף עד H4/H3/H2 הבא
- וכן הלאה...

**פסאודו-קוד**:
```javascript
function getNextHeadingLevel(currentLevel) {
    // עבור H2 (level=2): עצור רק ב-H2
    // עבור H3 (level=3): עצור ב-H3 או H2
    return Array.from({length: currentLevel - minLevel + 1}, (_, i) => `H${minLevel + i}`);
}
```

#### ג. תמיכה בדגל no-accordion
בדיקה לפני המרה:
```javascript

    return; // דלג על כותרת זו

```

יצירת classes לכל רמה:
```css

.sub-accordion-level-2 { /* H3 */ }
.sub-accordion-level-3 { /* H4 */ }
/* ... */
```

או שימוש ב-CSS variables:
```css

    --indent: calc(var(--level, 0) * 20px);
    padding-right: var(--indent);
}
```

## 12. קוד לבדיקה (Pseudo-code)

```javascript
function convertHeadingsToSubAccordions(container, levelStart = 2, levelEnd = 6) {
    const currentLevel = `h${levelStart}`;
    const headings = container.querySelectorAll(currentLevel);

    headings.forEach(heading => {
        // בדיקת דגל
        if (heading.classList.contains('no-accordion')) return;

        // איסוף תוכן עד כותרת באותה רמה או גבוהה יותר
        const contentElements = collectUntilSameOrHigherLevel(heading, levelStart);

        if (contentElements.length > 0) {
            const subAccordion = createSubAccordion(heading, contentElements, levelStart);

            // רקורסיה - עיבוד רמה הבאה בתוך התת-אקורדיון שנוצר
            if (levelStart < levelEnd) {
                const subBody = subAccordion.querySelector('.sub-accordion-body');
                convertHeadingsToSubAccordions(subBody, levelStart + 1, levelEnd);
            }
        }
    });
}

function collectUntilSameOrHigherLevel(heading, currentLevel) {
    const stopTags = Array.from({length: currentLevel - 1}, (_, i) => `H${i + 2}`);
    // H2: עצור ב-['H2']
    // H3: עצור ב-['H2', 'H3']
    // H4: עצור ב-['H2', 'H3', 'H4']

    let contentElements = [];
    let nextElement = heading.nextElementSibling;

    while (nextElement && !stopTags.includes(nextElement.tagName)) {
        contentElements.push(nextElement);
        nextElement = nextElement.nextElementSibling;
    }

    return contentElements;
}
```
